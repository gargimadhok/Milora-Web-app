# Milora Tech site — GitHub Pages

Files:
- `index.html` — marketing site (embeds the walkthrough)
- `walkthrough.html` — product walkthrough video page
- `dashboard.html` — the pricing dashboard (linked as "Client login" / "Open the dashboard")

Deploy:
1. Create a new GitHub repo and upload these three files to its root.
2. Repo → Settings → Pages → Source: "Deploy from a branch", branch `main`, folder `/ (root)`. Save.
3. The site goes live at `https://<username>.github.io/<repo>/` within a minute or two.

Custom domain: add it under Settings → Pages → Custom domain.
